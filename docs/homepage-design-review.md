# 主页设计分析与调整

## 核心判断

现有站点的插画封面、墨黑／纸白／荧光黄配色和档案式导航已经形成辨识度。主页的主要问题是信息顺序：访问者先看到自我介绍，真实项目却藏在独立作品页；原来的三张精选卡片使用示意标题和参考图，与正式档案没有对应起来。

此次采用 design-taste-frontend 的内容与构图检查，以及 impeccable 的渐进改进方法，保留现有视觉语言，优先缩短从进入网站到看到作品的距离。

## 内容依据

- 站点名称为 HAOQI / STUDIO，主体为浩祈的个人创作实践。
- 已有四个游戏项目：《残片人生》《傩面之囚》《五秒真男人》《泡涌》。
- 前三个项目有独立 B 站演示链接；《五秒真男人》《泡涌》另有 TapTap 商店页与真实作品素材。
- 已有一组阳朔摄影，拍摄日期为 2026.08.27。
- 已有十二个含曲目的音乐专辑档案，属于音乐收藏与聆听记录。
- 首页已有个人头像和插画背景，可继续使用。
- 既有完整作品页包含交互式档案浏览，不需要复制到主页首屏。
- 网站支持混合、中文、英文、日文和俄文。

## 发现与处理

| 原有问题 | 对访问者的影响 | 本次调整 |
| --- | --- | --- |
| 作品按钮跳转独立页面 | 下滑浏览和进入作品是两条不同动线 | 按钮与页尾下滑提示均定位到 `#work` |
| 自我介绍和占位统计位于作品之前 | 要先读较长的介绍才能看到成果 | 游戏、摄影、音乐先于关于与能力介绍；移除占位统计 |
| 精选作品为示意内容 | 作品名称、图片与真实档案不一致 | 直接读取正式内容数据，展示项目名称、真实素材和演示／商店入口 |
| 主页展开全部空槽位 | 黑色占位内容拉长页面 | 主页精选已提供内容，完整档案仍保留原来的整理结构 |
| 标题循环打字、删除 | 首次阅读可能遇到不完整的标题 | 主页标题直接完整呈现，首屏标题在各语言下保持两行 |
| 平板上的完整导航挤压语言入口 | 导航文字互相靠近、难以点击 | 主页在 1200px 以下使用折叠菜单，关闭时移出键盘焦点顺序 |

## 现在的浏览结构

封面与身份说明 → 四个游戏项目 → 阳朔摄影 → 音乐精选 → 关于与创作能力 → 联系方式。

作品区使用大字号项目索引。未提供封面的项目保留名称与演示入口；《五秒真男人》《泡涌》展示图标、作品介绍、宣传图、海报和实机截图。两者共用支持分类、缩略图、前后切换与大图查看的图库，也用于原有 Work 详情面板。摄影使用已有原图，音乐使用已有专辑封面；音乐明确标为收藏。

顶部导航沿用原来的独立页面入口：Work 打开 `/work.html` 的 3D 档案页面，Photography、Music、Contact、About 也各自打开原页面。首页圆形按钮、下滑提示和精选区分类入口使用页内定位。首页下滑精选与独立 Work 档案是两个不同入口。

## 实现位置

- `src/home-portfolio/HomePortfolio.jsx`：主页精选内容、五种语言文案、作品入口及播放请求。
- `src/home-portfolio/home-portfolio.css`：主页专用排版、响应式布局、交互和焦点样式。
- `src/main.jsx`：主页顺序、页内导航、静态标题及现有组件衔接。
- `src/game-project/`：两个游戏在首页与 Work 详情中共用的介绍、商店入口和图库。
- `docs/game-media-sources.json`：素材来源及用户上传图片的对应关系。

作品、相册与专辑数量从实际数据计算。继续向 `src/content.js` 添加已完成内容，主页计数随数据更新；摄影展示首个已发布相册，音乐展示前四张可播放专辑。

## 验证与边界

使用真实浏览器检查 1440、768、390、320px 四档宽度，覆盖五种语言、页内跳转、折叠菜单、摄影预览、Escape 关闭和全站音乐播放。检查图片加载、首屏标题行数、横向溢出和运行时错误，并查看桌面、平板和手机截图。

导航恢复后，另行验证桌面与手机端的 Work 入口、`/work.html` 直接刷新、三维画面、游戏／摄影／音乐分类，以及各分类的选择、抽取和归位。原有档案记录分别为 11、11、21 份；Work 组件、三维场景、专用样式和内容数据在本次导航修复中均未更改。

生产构建通过；本次新增模块的 Taste Skill 源码检查为 0 FAIL、0 WARN。修改前自动截图巡检在浏览器截图步骤超时，已保留可用的原始截图。修改后的自动巡检还会对既有品牌的等宽标签、档案编号、细线、悬浮导航和折叠播放器提出通用风格提示；这些不等同于功能缺陷，也没有把完整扫描描述为无条件通过。实际可读性问题另行修复，包括浅色区域灰字的对比度、偏小的说明文字和平板导航拥挤。

《残片人生》《傩面之囚》的游戏封面仍待提供；《五秒真男人》的 7 张商店素材与《泡涌》的 9 张用户素材已归档。WORK-04 从空槽位补充为《泡涌》，档案总槽位数保持不变。原始图片不作修改，网页使用保持比例的 WebP 与缩略图。本次只完成本地代码与预览，没有发布到线上。
