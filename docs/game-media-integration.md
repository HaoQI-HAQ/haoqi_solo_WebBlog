## 三维游戏光盘

最新确认方案已替换正式 Work 的模型。《五秒真男人》和《泡涌》使用完整图标纸封面与透明彩色游戏盒边框，正面没有遮挡角色的盘孔／卡扣；背面展示宣传图、作品名称和档案编号。音乐使用纸套与黑胶唱片，摄影使用固定外部尺寸的档案相框。灰白档案阵列在选中前便显示已有作品的封面与主题色，空档案保持浅色。

没有实际素材的档案使用相应类别的素色模型与档案编号。切换时立即移除旧作品素材；异步请求按选择版本校验，过期图片释放，不覆盖当前作品。贴图完成时主动请求渲染，避免模型静止后图片迟迟不显示。模型替换或页面卸载时，释放模型拥有的网格、材质和贴图。

浏览器中实际用鼠标抽取、旋转并查看两部游戏的正反面，核对实际图片路径与背面方向；也检查音乐唱片的正反面与缺少图标的档案。模型拾取几何回归和生产构建通过。

新版模型另核对了摄影外框及照片比例、音乐黑胶与纸套正反面、三类模型的鼠标抽取／旋转／空白归位、缺失素材回退、快速切换时过期贴图释放，以及模型稳定后的停止渲染。390px 和 768px 下三类模型均完整位于标题与详情区之间；窄屏详情使用上下布局。轻量生产构建与颜色提取、几何拾取测试通过。

## 阵列颜色连续性与唱片抽取

`artworkCatalog.js` 保存本地原始素材提取的主题色。12 张真实 MP3 内嵌封面和一张摄影预览生成到 `public/media/work-archive/covers/`，最长边 512px，共约 504 KiB；加上现有游戏图标，阵列封面预加载约 665 KiB。主题色与封面在阵列首次出现前准备好，选择时直接复用同一套内容。背景使用分类实例模型与共享图集，无需为每个位置创建独立贴图，也不再加载旧 GLB。

音乐浏览时只有居中的唱片套；抽取先抬起纸套，再向右滑出黑胶并轻转约 25°。归位先收回唱片，再把档案放回槽位；快速返回、重新抽取会从当前进度继续。每次打开或刷新均默认完整动效，页面底部可手动切换“动态／完整”与“动态／简化”，手动切换仅对当前页面生效；系统偏好不会再自动触发静态跳转。鼠标中途拖动并按 Esc 的释放状态也已核对。

重建预览与主题色：`node scripts/build-archive-artwork.mjs`。外置媒体部署时，须同时上传新增的 `media/work-archive/covers/`；`VITE_MEDIA_BASE` 同样适用于这些预览路径。
