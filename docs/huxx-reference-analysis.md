# huxx 参考站拆解

本次读取公开 HTML、CSS、JS；扩展浏览器超时后，使用设计技能的 Chrome 巡检完成 About 开场、最爱和游戏库截图核对，记录于 .taste-skill/huxx-about-reference/。首页和作品集仅核对源码结构。借鉴信息层级、构图和交互，不迁移作者个人经历。

## 首页

[来源](https://huxx.me/zh/)：导航后依次为姓名与方向、简介、统计、经历、技能及 About 入口，穿插键盘小游戏提示。可借鉴“大标题建立身份—项目证明能力—兴趣补充人格”的阅读顺序；经历、技能和数字使用本站已有资料，小游戏只作独立增强。

## 作品集

[来源](https://huxx.me/zh/portfolio/)：先总述，再以四个方向入口组织游戏设计、游戏开发、AI 应用开发、技术美术，最后汇入项目库。不同方向使用不同密度的项目展示，兼顾精选与完整索引。本站可沿用分区导航、封面与职责摘要层级，以自己的项目分类和链接生成内容。

## About

[来源](https://huxx.me/zh/aboutme/)：兴趣以左右交替的人物、便签、照片构成海报；奶油底、粗边框与硬阴影贯穿页面。旅程铭牌后接双列介绍、最爱网格和游戏库。2:3 封面；桌面滑块调整卡宽，手机最爱两列、库三列。类型可多选，按任一标签匹配并更新计数；“全部”重置。标题可切换游戏与动画。输入控件是大小滑块，并无搜索框。

[CSS 来源](https://huxx.me/_astro/aboutme@_@astro.1eF3IyqG.css)；交互脚本内嵌于 About HTML。可迁移构图、最爱标记、筛选和响应式规则。
