# Work 页面音效来源

Work 使用 [LBEILC/RhineLabUI](https://github.com/LBEILC/RhineLabUI) 的声音设计和交互语义：档案实体使用短促的薄玻璃共鸣，系统界面使用电子点击、升降扫音和确认短音，启动过程按实际画面时间触发。

`src/work-archive/workSoundSynth.js` 的 17 类声音合成参数和包络逻辑改编自上游 `src/audio.ts`，保留 Copyright (c) 2026 LBEILC。此代码遵循项目随附的 [MIT 许可](../src/work-archive/LICENSE)。除逐字输入短音外，其余声音由 Web Audio 振荡器与固定种子的噪声现场合成，无需额外音效文件下载。

`src/work-archive/typingSamples.js` 包含上游使用的三个 38 毫秒、48 kHz、单声道短音，来自《明日方舟》特别映像《莱茵生命：访问》（BV1rr4y1b7sz）约 6.864、6.906、6.948 秒。短音保留上游去直流、入出端淡变及统一增益处理，不包含人声、长段音轨或视频。它们是原片摘录，权利仍归原作者；MIT 代码许可不将这些波形重新授权为原创或 MIT 音频。精确切点、源文件校验值及处理记录保存在 [typing-source.json](../src/work-archive/typing-source.json)。

本次只移植启动和交互音效，不引入原站三轨背景配乐。网站的音乐收藏与原有播放器继续负责音乐播放。

浏览器离线验证入口为 `.taste-skill/synth-fixture.html`，脚本为 `.taste-skill/verify-work-synth.mjs`。检查实际 OfflineAudioContext 输出的有限样本、非零声能、峰值余量、尾部归零、声源结束、节点断开、提前停止、快速连续触发及左右声像；数值检查不代替用户的耳机和扬声器试听。

控制器不在挂载时建立音频设备。全站扩展后，默认开启，第一次实际点击或按键自动解锁 Web Audio，不再要求单独点击开启；静音选择统一保存在 `haoqi-site-sound`。旧 Work 专用开关不迁入新的默认偏好。启动逐字音使用实际可见文字的增量，主提示音跟随既有启动时钟，阵列声音绑定实际揭幕，抽取和读取绑定实际操作。跳过、隐藏、Reduced 与大幅时间跳跃都不补播历史声音。

音效保持原站 0.8 主增益、0.55 效果增益及压缩参数，同时最多保留 10 个活动声部。网页隐藏时停止声音并挂起设备；跨页面共用同一设备，卸载全站 provider 才关闭。重新启用会恢复效果增益。全站播放器开始播放时只将音效降至平时的 40%，不改变音乐音量或曲目。

2026-10-24 验证：31 项单元回归通过；17 类声音在 48/44.1 kHz 下与提前停止、连续触发、声像共完成 38 次离线渲染；实际 Work 浏览器检查覆盖首次手势、完整启动、键盘切换、抽取、照片放大/关闭、归位、静音再开启、静音记忆及 320/390/768/1440 像素布局。手机底部为音效与动效控制留出独立触控区域。
