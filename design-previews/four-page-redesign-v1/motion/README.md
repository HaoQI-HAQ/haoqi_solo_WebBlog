# 四页动效预览

预览地址：`http://127.0.0.1:5173/design-previews/four-page-redesign-v1/motion/index.html`。

本目录是隔离的设计确认稿，不接入正式路由。首页与正式 Work / Photography / Music / Contact / About 源文件不作替换。

使用 impeccable `animate` 和 design-taste-frontend 的 motion 指导，不新增动画依赖。默认完整动态，每次刷新重置；可手动切换简化。普通反馈约 150ms，内容切换 350–500ms，摄影主图横向展开 760ms。页面是默认可见的最终布局，Web Animations API 只增加短暂过渡；切页、快速点击和重播都会取消旧入场，不阻塞内容。

主动作：摄影展开视野并从主图进入原图；音乐封面与曲目保持同一张专辑的连续性；Contact 主题选择影响邮件，复制后给出状态反馈；About 方向切换让作品接替说明。没有自动播音、无限装饰循环、滚轮劫持或全屏等待。

完整模式来自用户已表达的默认动态偏好，手动简化保留轻淡入和明确操作反馈。后续正式实现是否替换，以用户确认本预览为准。

验证覆盖四个页面的 1440 / 768 / 390 / 320px 布局、实际入场与重播、手动简化和刷新恢复；另在桌面和手机核对摄影展开/Escape/切页清理、连续专辑选择、真实音频播放/切歌/跨预览页延续、About 键盘选择、邮件主题以及复制成功与拒绝后的兜底。

Taste Skill 巡检的范围说明：预览控制条是有实际操作的工具界面，以 `data-ui` 标记，不能当作页面眉题。`few-pictures` 例外源自摄影只有一张实际原图，不为凑数添加别人的照片；`still-page` 例外源自巡检在约1.2秒后采样，短于830ms的入场已结束，实际动画由CDP重播和交互测试核对；`palette-cream` 与 `pill-nav` 保留已确认的站点配色和导航。无摄影视频素材，不引入无关片段。Space Grotesk 是既有品牌字体，时钟补零与原品牌圆环为有意义的保留。没有把这些通用风格项描述为整个正式站无条件通过。
