# 模型方案修订：封面与阵列适配

本目录保留模型修订与尺寸预览。方案已获确认，三类模型现已接入正式 [Work 页面](http://127.0.0.1:5173/work.html)，实现见 `src/work-archive/archiveObject.js`。

## 游戏封面

正面使用完整纸质封面，透过清透盒盖展示角色。光盘和固定卡扣放在封面背后的盒内；闭合时角色脸上没有孔洞、圆形卡扣或机械装饰。背面继续展示宣传图。开盒示意仅用于说明光盘的收纳位置。

## 摄影尺寸

上一版把外框按全景照片比例做得过长，未充分考虑现有阵列的槽位。这一版将摄影档案外框与当前模型统一，照片内窗保留原始比例，以卡纸上下留白补足。

实际读取当前 GLB 的包围盒约为宽 5.0104、高 3.7000、厚 0.3764；场景列间距为 5.2，前后间距为 0.62。新摄影外框的建议上限为 5.0 × 3.7 × 0.35，控制在原占位内。原片约为 2.607:1，这个比例只应用于内侧照片，不应用于整个模型外框。

浏览时保留既有档案阵列与间距，选中档案使用对应类别的新模型。摄影相框抽取前后保持同一外框，详情中的照片可打开原比例大图。
